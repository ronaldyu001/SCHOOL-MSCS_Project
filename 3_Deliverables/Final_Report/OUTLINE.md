## Abstract (150 words)

### Problem, Project Statement, and Approach

- AI conversational assistants with long term conversational memory search a store built from past conversations, but nearly all of them use the user's query, embedded as-is, to search the store. This is often not a good search method.
- Example of when this naive method fails.
- A solution is to use a language model to rewrite the message into a query before searching. Give PPRO as an example of this. Give the drawback of PPRO.
